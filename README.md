# Interactive 7th Birthday Invitation

### Replace photos
Put your photos in the `images` folder using these exact names:

- cover.jpg
- main.jpg
- gallery1.jpg
- gallery2.jpg
- gallery3.jpg
- gallery4.jpg

You do NOT need to edit the HTML if you keep the filenames.

### Edit the invitation
Open `index.html` and change:
- [CHILD'S NAME]
- date
- time
- venue
- address
- dress code
- gift ideas

Open `script.js` to change the countdown date.

### GitHub Pages
Upload the files to your repository, then:
Settings → Pages → Deploy from branch → main → /root → Save.

The page is designed primarily for mobile, matching the pink/floral interactive invitation style from the reference.

### Home buttons
Every invitation section now has a small Home button in the upper-right corner that returns to the opening invitation.
